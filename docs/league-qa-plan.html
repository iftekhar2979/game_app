Before you start

Accounts you need

  • Commissioner — creates the league, owns every settings modal
  • Member — joins and drafts, never sees commissioner controls
  • Outsider — not a member; used for the private, full and closed cases
  • Admin — submits cheer competition results so scores land

Environment

  • An active season must exist — league creation hard-blocks without one
  • Two devices signed in as different members on the same league, for every realtime case
  • Seeded season cheer teams across at least two divisions
  • A way to kill the network (airplane mode) for the resilience area

How to log a case

  • Pass — you observed exactly the expected result
  • Fail — file a ticket with the case ID (e.g. F05) in the title
  • Blocked — you could not reach it; note what stopped you

Run order matters

  • A → B → C build the league the rest of the plan uses
  • E or F must complete before G, I and J have any data
  • K11 deletes the league — run it last
